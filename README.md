# ボディビルダー

## ゲーム概要
体を鍛え上げてボディビル大会を目指す、
マッチョ育成シミュレーションゲームです。

プレイヤーはトレーニングや各種ミニゲームを通じてキャラクターを成長させ、
理想の肉体を作り上げながら大会優勝を目指します。

## 制作時に目指したこと・意識したこと

### ・セーブ機能を前提とした拡張性のある設計
育成シミュレーションゲームとして、
長期的なプレイやデータの蓄積を前提とした構造を意識しました。  
そのため、セーブ／ロード機能を中心に据えた設計を行い、
今後の機能追加にも対応しやすい構成を目指しました。

### ・ミニゲームの再利用性と管理のしやすさ
ミニゲームをランダム生成にするのではなく、
あらかじめ複数パターンを用意し、それらを呼び出す構造を採用しました。  
これにより、各ミニゲームの調整や追加を容易にしています。

---

## そのために行ったこと

### ① セーブ／ロードシステムの設計
プレイヤーの成長状態や進行状況を保存できるよう、
データ構造を整理し、保存・復元処理を実装しました。  

- プレイヤーステータス  
- 進行状況  
- ミニゲーム結果  

などを管理対象とし、
将来的なデータ追加にも対応できる構造を意識しています。

### ② ミニゲーム管理システムの構築
複数のミニゲームを個別に実装し、
それらを管理・呼び出す仕組みを構築しました。  

- 各ミニゲームを独立した処理として設計  
- 状況に応じて適切なミニゲームを選択・実行  

とすることで、拡張性と保守性を確保しています。
